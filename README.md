# One Button App

A minimal Flutter app with one centered, enabled button. Clicking it has no action yet.

The app source is ready. Platform scaffolding and Flutter validation could not be
completed because macOS blocked access to the Flutter SDK in Downloads.

Once Flutter is accessible, run these commands from this folder:

```sh
flutter create --project-name onebuttonapp .
flutter run
```

The create command generates the platform runner files while preserving the existing app source.
